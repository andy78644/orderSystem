## 系統概述

### 🎯 主要功能

報價系統是一個簡化報價管理流程的工具，幫助您：
- ✅ 快速建立報價表單
- ✅ 輕鬆分享給廠商填寫
- ✅ 集中查看所有報價記錄
- ✅ 比較同一廠商的歷史報價

### 👥 角色說明

**管理員**
- 建立和管理報價表單
- 查看所有報價記錄
- 比較廠商報價

**廠商**
- 通過公開連結填寫報價
- 無需註冊或登入
- 可多次提交（如果允許）

## 管理員操作指南

### 1. 登入系統

1. 開啟報價系統網址
2. 輸入您的 Email 和密碼
3. 點擊「登入」

**預設管理員帳號**：
- Email: `admin@example.com`
- Password: `admin123`

⚠️ **首次登入後請立即修改密碼！**

---

### 2. 建立報價表單

#### 步驟 2.1：進入新增頁面

1. 登入後，點擊右上角的「**建立新表單**」按鈕
2. 或在導航列點擊「**表單列表**」→「建立新表單」

#### 步驟 2.2：填寫基本資訊

在「基本資訊」區塊填寫：

| 欄位 | 說明 | 範例 |
|------|------|------|
| **表單標題** | 此次詢價的名稱 | `2025年第一季辦公用品詢價` |
| **廠商名稱** | 要詢價的廠商全名 | `台灣文具供應有限公司` |
| **廠商電話** | 聯絡電話 | `02-1234-5678` |
| **廠商 Email** | 用於接收表單連結 | `sales@vendor.com` |

**填寫選項**：
- ☑️ **允許廠商修改報價**：勾選後，廠商可多次提交更新報價
- ☐ 不勾選：廠商只能提交一次

#### 步驟 2.3：新增商品項目

在「商品清單」區塊：

1. **填寫第一項商品**：
   - **商品名稱**：例如 `A4 影印紙`
   - **規格**：例如 `70磅 白色 500張/包`（選填）
   - **數量**：例如 `100`
   - **單位**：例如 `包`

2. **新增更多商品**：
   - 點擊「**+ 新增商品**」按鈕
   - 繼續填寫其他商品資訊

3. **移除商品**：
   - 點擊商品右側的「移除」按鈕
   - 至少需保留一個商品

#### 步驟 2.4：儲存表單

1. 確認所有資訊正確
2. 點擊底部的「**儲存表單**」按鈕
3. 系統會自動跳轉到表單列表

✅ **完成！** 您已成功建立報價表單。

---

### 3. 分享報價表單給廠商

#### 步驟 3.1：複製公開連結

1. 在「**表單列表**」頁面
2. 找到要分享的表單
3. 點擊「**複製連結**」按鈕（綠色按鈕）
4. 系統會顯示「連結已複製到剪貼簿」

#### 步驟 3.2：發送給廠商

將複製的連結傳送給廠商：

**Email 範本**：
```
親愛的 [廠商名稱]：

誠摯邀請貴公司為以下商品提供報價：

表單標題：[表單標題]
報價截止日：[日期]

請點擊以下連結填寫報價：
[貼上公開連結]

如有任何問題，請隨時與我們聯繫。

謹致
[您的公司名稱]
```

**其他方式**：
- LINE / WhatsApp：直接傳送連結
- 簡訊：貼上短網址
- QR Code：使用線上工具生成 QR code

---

### 4. 查看報價記錄

#### 步驟 4.1：進入表單詳情

1. 在「**表單列表**」頁面
2. 點擊要查看的表單的「**查看報價**」按鈕（藍色）
3. 進入報價詳情頁面

#### 步驟 4.2：查看報價資料

報價詳情頁面顯示：

**表單資訊**：
- 表單標題
- 廠商名稱、電話、Email
- 表單狀態（開啟/關閉）
- 建立時間

**報價記錄**：
- 每次提交的報價都會顯示
- 包含提交時間
- 顯示每個商品的單價和小計
- 顯示總金額

**如果沒有報價**：
- 顯示「尚無報價記錄」
- 提示檢查表單狀態或聯繫廠商

### 5. 比較廠商報價

#### 使用場景

當您想要：
- 查看同一廠商在不同時間的報價變化
- 追蹤價格趨勢
- 找出最優惠的報價時間

#### 步驟 5.1：進入比較頁面

1. 點擊導航列的「**比較報價**」
2. 或從表單列表頁面找到「比較廠商報價」區塊

#### 步驟 5.2：選擇廠商

1. 在下拉選單中選擇要比較的廠商
2. 顯示格式：`廠商名稱 (X 張報價表單)`
3. 只會列出有報價記錄的廠商

#### 步驟 5.3：查看比較結果

點擊「**查看比較**」後，系統會顯示：

**比較表格說明**：

| 欄位 | 說明 |
|------|------|
| **商品名稱** | 商品的名稱 |
| **規格** | 商品規格（如果有） |
| **單位** | 計價單位 |
| **數量** | 詢價數量 |
| **表單1、表單2...** | 按時間順序排列的各次報價 |
| **變化** | 相較於前一次的價格變化 |

**價格標示**：
- ⭐ **黃色星號**：該商品的最低價
- 🔵 **藍色數字**：正常報價
- ❌ **橫線**：該次報價未包含此商品

**價格變化**：
- ↓ **綠色向下箭頭**：價格下降（例如：`-$50 (-10%)`）
- ↑ **紅色向上箭頭**：價格上漲（例如：`+$30 (+5%)`）
- `-` **無變化**：首次報價或價格相同

**範例**：
```
商品：A4 影印紙
表單1 (2025/01/01)：$500
表單2 (2025/02/01)：$450  ↓ -$50 (-10%)  ⭐
表單3 (2025/03/01)：$480  ↑ +$30 (+6.7%)
```

#### 步驟 5.4：快速查看統計

在比較頁面下方還可以看到：

**廠商報價統計表**：
- 列出所有有報價的廠商
- 顯示每個廠商的報價表單數
- 快速點擊「查看比較 →」跳轉到該廠商的比較頁面

### 6. 管理表單

#### 6.1 編輯表單

1. 在表單列表找到要編輯的表單
2. 點擊「**編輯**」按鈕（灰色）
3. 修改表單資訊或商品項目
4. 點擊「**儲存表單**」

⚠️ **注意**：
- 如果已有報價記錄，修改表單可能影響報價數據
- 系統會顯示警告提示
- 建議謹慎修改已有報價的表單

#### 6.2 開啟/關閉表單

**關閉表單**：
1. 點擊「**關閉表單**」按鈕
2. 確認操作
3. 廠商將無法再提交報價
4. 已提交的報價不受影響

**重新開啟**：
1. 點擊「**開啟表單**」按鈕
2. 廠商可以繼續提交報價

**使用時機**：
- ✅ 報價截止時關閉表單
- ✅ 暫時停止收集報價
- ✅ 已選定廠商後關閉其他表單

#### 6.3 複製表單

**用途**：快速建立相似的表單

1. 點擊「**複製**」按鈕
2. 系統會：
   - 複製所有商品項目
   - 複製廠商資訊
   - 標題加上「- 複製」後綴
3. 進入編輯頁面
4. 修改需要的資訊（例如日期、數量）
5. 儲存

**優點**：
- 不需要重新輸入所有商品
- 快速建立定期詢價表單
- 保持商品資訊一致性

#### 6.4 刪除表單

⚠️ **危險操作！無法復原！**

1. 點擊「**刪除**」按鈕（紅色）
2. 系統會顯示確認訊息：
   ```
   確定要刪除此表單？
   此操作無法復原，所有相關報價記錄也會被刪除。
   ```
3. 確認後刪除

**刪除後會移除**：
- ❌ 表單本身
- ❌ 所有商品項目
- ❌ 所有報價記錄
- ❌ 無法恢復

**建議**：
- 改用「關閉表單」功能保留歷史記錄
- 確認不再需要這些資料再刪除

## 廠商操作指南

### 1. 開啟報價表單

#### 步驟 1.1：點擊連結

1. 收到管理員傳送的連結
2. 點擊連結開啟報價頁面
3. **無需註冊或登入**，直接填寫

#### 步驟 1.2：確認資訊

報價頁面會顯示：
- 📋 表單標題
- 🏢 您的公司名稱
- 📞 聯絡電話
- 📧 Email

**如果資訊有誤**：
- 請聯繫發送表單的管理員
- 管理員可以編輯表單資訊

---

### 2. 填寫報價

#### 步驟 2.1：查看商品清單

表格顯示以下資訊：

| 欄位 | 說明 |
|------|------|
| **商品名稱** | 需要報價的商品 |
| **規格** | 商品的詳細規格 |
| **數量** | 需求數量 |
| **單位** | 計價單位 |
| **單價** | 🔸 **您需要填寫** |
| **小計** | 自動計算（單價 × 數量） |

#### 步驟 2.2：輸入單價

1. 在「**單價**」欄位輸入每單位的價格
2. 只需輸入數字，不用加貨幣符號
3. 可使用小數點（例如：`125.50`）
4. 系統會自動計算小計

**範例**：
```
商品：A4 影印紙
規格：70磅 白色 500張/包
數量：100 包
單價：125 (您輸入)
小計：12,500 (自動計算)
```

#### 步驟 2.3：填寫所有商品

1. 逐一填寫每個商品的單價
2. 必須填寫所有商品
3. 不可留空

**即時預覽**：
- 填寫單價後，小計會立即更新
- 頁面底部顯示「**總金額**」

---

### 3. 提交報價

#### 步驟 3.1：檢查資料

提交前請確認：
- ✅ 所有商品的單價都已填寫
- ✅ 數字正確無誤
- ✅ 總金額符合預期

#### 步驟 3.2：提交

1. 點擊底部的「**提交報價**」按鈕（綠色）
2. 系統處理提交（約1-2秒）
3. 顯示成功訊息

**成功提交後**：
```
✅ 報價已成功提交！

您的報價已記錄，管理員將會收到通知。
感謝您的配合！

本次報價總金額：$XX,XXX
```

#### 步驟 3.3：完成

- 可以關閉頁面
- 或保存連結以便日後查看

---

### 4. 修改報價

#### 能否修改？

取決於管理員的設定：

**允許修改**：
- ✅ 可以重新開啟連結
- ✅ 填寫新的單價
- ✅ 再次提交
- ℹ️ 系統會記錄為新版本

**不允許修改**：
- ❌ 提交後無法再次填寫
- ❌ 重新開啟連結會顯示：
  ```
  此表單只允許提交一次報價，您已經提交過了。
  ```

#### 如何修改？

如果允許修改：

1. **重新開啟連結**
2. **填寫新的單價**
   - 系統會顯示上次的報價（參考用）
   - 輸入新的單價會覆蓋舊的
3. **提交新報價**
4. **系統保留歷史**
   - 舊報價不會被刪除
   - 管理員可以看到所有版本

### 5. 常見情況

#### 情況 1：表單已關閉

```
⚠️ 此表單已關閉，無法提交報價
```

**原因**：
- 報價截止日已過
- 管理員已關閉表單
- 已選定其他廠商

**建議**：
- 聯繫管理員確認
- 詢問是否可以重新開啟

#### 情況 2：填寫錯誤

**忘記填寫某個商品**：
```
❌ 錯誤：請填寫所有商品的單價
```
- 檢查是否有空白欄位
- 填寫後重新提交

**輸入非數字**：
```
❌ 錯誤：單價必須是數字
```
- 只能輸入數字和小數點
- 不要輸入文字或符號

#### 情況 3：連結失效

```
❌ 錯誤：表單不存在
```

**可能原因**：
- 連結複製不完整
- 表單已被刪除
- 網址輸入錯誤

**解決方式**：
- 重新向管理員索取完整連結
- 確認連結沒有被截斷

## 常見問題

### 管理員 FAQ

#### Q1：如何修改管理員密碼？

**答**：目前系統尚未提供密碼修改功能（Phase 1 版本）。如需修改密碼，請聯繫系統管理員直接在資料庫中更新。

**臨時解決方案**：
1. 使用強密碼作為 `ADMIN_PASSWORD` 環境變數
2. 不要在公開場合分享密碼
3. 定期更換密碼

#### Q2：可以建立多個管理員帳號嗎？

**答**：目前版本（Phase 1）只支援單一管理員帳號。多用戶管理功能規劃在 Phase 2 開發。

#### Q3：表單可以設定報價截止日期嗎？

**答**：目前系統沒有自動截止日期功能。建議：
- 在表單標題中註明截止日（例如：`2025/03/31前提交`）
- 截止後手動關閉表單
- 或在發送給廠商的訊息中說明

#### Q4：報價資料可以匯出嗎？

**答**：目前版本不支援直接匯出。這是 Phase 2 規劃的功能。

**臨時解決方案**：
- 手動複製報價資料
- 或使用螢幕截圖
- 等待 Phase 2 更新（將支援 Excel/PDF 匯出）

#### Q5：可以同時向多個廠商詢價嗎？

**答**：可以！步驟如下：
1. 為每個廠商分別建立表單
2. 商品項目可以相同（使用「複製表單」功能）
3. 修改廠商名稱和聯絡資訊
4. 分別發送連結給不同廠商

#### Q6：如何追蹤廠商是否已提交報價？

**答**：
1. 進入「表單列表」
2. 查看「報價次數」欄位
3. 顯示「X 次」表示已提交
4. 顯示「0 次」表示尚未提交

#### Q7：刪除表單後可以恢復嗎？

**答**：❌ **無法恢復！** 刪除是永久性的。建議：
- 使用「關閉表單」代替刪除
- 定期備份重要資料
- 刪除前再三確認

---

### 廠商 FAQ

#### Q1：為什麼我無法修改已提交的報價？

**答**：這取決於管理員的設定：
- 如果表單設定為「只能提交一次」，提交後就無法修改
- 如果需要修改，請聯繫管理員
- 管理員可以：
  - 重新發送新表單
  - 或修改表單設定允許多次提交

#### Q2：提交後可以看到其他廠商的報價嗎？

**答**：❌ **不可以**。報價資料是保密的：
- 廠商只能填寫自己的報價
- 無法查看其他廠商的報價
- 只有管理員能看到所有報價

#### Q3：報價單價可以包含稅嗎？

**答**：這由您與管理員約定：
- 通常建議註明「含稅」或「未稅」
- 在聯繫管理員時確認
- 建議統一標準（全部含稅或全部未稅）

#### Q4：可以對某些商品不報價嗎？

**答**：❌ **不可以**。系統要求填寫所有商品的單價。如果：
- 某商品無法供應 → 建議填寫「0」並聯繫管理員說明
- 某商品需要另行報價 → 填寫估計值並備註

#### Q5：如何確認報價已成功提交？

**答**：提交成功會顯示：
```
✅ 報價已成功提交！
您的報價已記錄...
```

如果沒有看到此訊息：
- 檢查網路連線
- 確認所有欄位都已填寫
- 重新嘗試提交

#### Q6：報價連結會過期嗎？

**答**：連結本身不會過期，但：
- ⚠️ 表單可能被管理員關閉
- ⚠️ 表單可能被刪除
- 建議在收到連結後盡快填寫

## 💡 使用技巧

### 管理員技巧

#### 技巧 1：使用表單命名規範

建議的命名格式：
```
[年度/季度] - [類別] - [廠商] - [日期]

範例：
- 2025Q1 - 辦公用品 - ABC文具 - 0315
- 2025 - 電腦設備 - XYZ科技 - 0420
```

**好處**：
- 易於搜尋和識別
- 清楚的時間序列
- 方便長期管理

#### 技巧 2：建立表單範本

對於定期詢價：
1. 建立一個標準表單
2. 使用「複製」功能快速建立新表單
3. 只需修改日期和數量

**適用於**：
- 每月定期採購
- 固定供應商
- 重複性商品

#### 技巧 3：分階段詢價

大型採購可以分階段：
1. **第一輪**：粗略詢價（品項較少）
2. **第二輪**：細部報價（詳細規格）
3. **第三輪**：議價（針對特定品項）

#### 技巧 4：使用比較功能追蹤市場價格

定期向同一廠商詢價：
- 每月一次
- 使用「比較報價」追蹤價格趨勢
- 發現異常波動時及時溝通
